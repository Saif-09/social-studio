# ChatGPT image prompts

Tell the user: one new ChatGPT chat, send STYLE first, then each SCENE one by one in the same chat, save to ~/Downloads in order. For a later part of the same story, use the same chat.

## STYLE block (template; swap the style words for the brand's look)
Example below is the Your Brand festival-story look. Other brands: write their own style line in the brand file and paste it here.

For the next N images keep one consistent style: flat 2D Indian storybook illustration, clean bold dark outlines, simple shapes, rich warm colours (deep indigo night, saffron, marigold, red, cream), soft diya glow, subtle Madhubani patterns on clothes, cinematic lighting. Vertical portrait 2:3. No text, no letters, no watermark. Keep every character's face, clothes and colours identical in every image. Modest, respectful poses; no man and woman touching or sitting close.
Characters: <NAME: age, clothes, hair, one distinctive item> (list every recurring character)

## SCENE line
SCENE n: <place + time of day>. <who does what, where they look>. <2-3 props that sell the setting>. <light>.

Rules: one action per scene; say "a few steps away"/"apart" for any man+woman; babies wrapped in white; deities with halo, calm; leave the bottom third simple (captions go there).
