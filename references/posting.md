# Posting and scheduling

- Times (IST): 4–5 posts/day, ≥2 h apart. Festival content on its own day, morning. Series: same time daily.
- The user schedules through a browser agent in Meta Business Suite. Write the prompt to a file, `pbcopy` it, give the file names to upload.

## Business Suite prompt template
You are helping me in Meta Business Suite (business.facebook.com) for "<Brand>": Facebook Page "<Page>" AND Instagram @<handle>. Timezone IST. Today is <day date>.
Rules: I upload files myself (tell me the file name, wait for "uploaded"). Paste captions EXACTLY. Always Schedule, never Publish now. Never boost, change settings or touch posts not named here. Say "Done: <step>" after each step.
=== STEP n: <Reel/Carousel> · <Day date> · <time> ===
File: <name>. Placements: Facebook + Instagram. Caption: <<< ... >>>
(Replace an existing scheduled item: "if Edit can replace the video do that, else delete ONLY that item and recreate it at the same time".)
=== FINAL CHECK === List Content → Scheduled for <range> with time, first line, FB/IG; flag missing/doubled/moved.

## Captions
Hook line + 2–3 short lines + CTA with the site path + comment ask + 6–8 hashtags. Brand language rules apply (astro brand: Hinglish, no em dashes, no "!", no fear, no disclaimers). Pinned comment: a question people can answer in one word.
